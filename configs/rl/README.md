# RL configurations

- `timeple_single_grpo_iou_dfl_format.yaml`: GRPO baseline.
- `timeple_csdo.yaml`: Counterfactual Span Distribution Optimization.
- `timeple_tr_spd.yaml`: Trust-Region Span Posterior Distillation.

The included `data/rl_train.jsonl` documents the expected schema and is used for both train and validation fields in the illustrative configurations.
